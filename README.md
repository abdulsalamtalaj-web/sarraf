# صرّاف

تطبيق أندرويد مجاني لأهل سوريا: سعر الدولار والتركي واليورو والذهب بالسوق، مع تحويل فوري بين الليرة السورية
الجديدة والقديمة (= الجديدة × 100) والعملات وغرامات الذهب. بدون إعلانات وبدون أي خدمة مدفوعة.

- **صفحة التحميل:** https://abdulsalamtalaj-web.github.io/sarraf/
- **آخر إصدار:** https://github.com/abdulsalamtalaj-web/sarraf/releases/latest

---

## ⭐ إضافة تعديل جديد (عدّل ← push ← التحديث بيوصل للناس)

1. عدّل اللي بدك ياه (الواجهة بـ `app/www/`، الإعدادات بـ `app/www/config.js`...).
2. احفظ وارفع:
```bash
git add -A
```
```bash
git commit -m "شو تغيّر بجملة وحدة"
```
```bash
git pull --rebase
```
```bash
git push
```
3. GitHub Actions بيعمل لحاله (حوالي 5 دقايق): اختبارات ← بناء APK موقّع ← Release فيه `sarraf.apk` ← تحديث `version.json`.
   تابعه من تبويب **Actions** بالمستودع.
4. كل مستخدم بيفتح التطبيق بيطلعله "في تحديث جديد" مع رسالة الـ commit كـ "شو الجديد"، وزر "حدّث الآن" بينزّل ويثبّت جوا التطبيق.

> `git pull --rebase` مهم لأن الـ Action بيرفع تعديل صغير على `docs/version.json` بعد كل نسخة.

**المعلومة الطبية وفيديو الأسبوع:** عدّل `docs/tips.json` واعمل push. بيوصل للتطبيق خلال دقايق **بدون** تحديث (وما بيبني نسخة جديدة).

## كيف تعمل الأسعار

1. **بدون Worker** (الوضع الحالي): التطبيق بيقرأ قناة التلغرام مباشرة (`exchange_Currencyy` أساسية و`aboothman33` تانية) كل 5 دقايق.
2. **مع الـ Worker** (اختياري، القسم الأخير): كل دقيقة من الخادم، وبيضيف رسم بياني لآخر 30 يوم.
3. **القناتين مع بعض**: إذا الفرق أكتر من 2% بيطلع تنبيه "المصادر مختلفة".
4. **فحص منطقي**: رفض الشراء > المبيع، والأرقام الشاذة، وأي قفزة > 10% بدون تأكيد.
5. **المحلّل بيفهم**: الأرقام العربية، النقطة كفاصل آلاف (`11.650`)، المدن (دمشق أولاً)، الليرة القديمة، المبيع قبل الشراء...
6. **الذهب**: من القناة إذا نشرته، وإلا الأونصة العالمية (gold-api.com مجاني) × دولار السوق مع "سعر تقديري".
7. **بلا نت**: آخر أسعار محفوظة مع وقتها وتنبيه إنها قديمة. **سحب الشاشة لتحت** بيحدّث فوراً.

## الخادم (Cloudflare Worker) — اختياري

بيخفّف الضغط على قناة التلغرام، وبيعطي رسم بياني لآخر 30 يوم. التطبيق بيشتغل بدونه.

```bash
cd worker
npm install
npx wrangler login
npx wrangler kv namespace create HISTORY
```
حط الـ `id` اللي بيطلع بـ `worker/wrangler.toml` مكان `PUT_YOUR_KV_ID_HERE`، وبعدين:
```bash
npx wrangler deploy
```
وحط الرابط مع `/rates` بـ `app/www/config.js` ← `API_URL`، واعمل push.
الحدود المجانية: 100,000 طلب باليوم.
